# Constraints

This section records the constraints that govern the implementation of the
system. We focus primarily on technical constraints.

## Technical constraints

- The application works with all major desktop environments on modern Linux
  distributions like Ubuntu, PopOS, and Arch Linux. 

- Users can build custom clients to work with the solution in case they want to
  support desktop environments other than [COSMIC Desktop][COSMIC].

- The solution is built under a liberal open-source license.

[COSMIC]: https://system76.com/cosmic
